# 꿈별이의 룸메이트 찾기

행복기숙사 인스타그램 이벤트용 미니게임.

## 게임 구조
- 기본 꿈별이만 좌우로 이동합니다.
- 세 유형의 룸메이트 꿈별이는 각자 자기 자리에 가만히 있습니다.
- 꿈별이가 룸메이트에게 가까이 가면 게임이 멈추고 유형 팝업이 뜹니다.
- `계속하기`를 누르면 다시 이동합니다.
- 세 명을 모두 만나면 마지막 선택 화면이 나타납니다.
- PC: ← / → 이동, Space 점프
- 모바일: 화면 아래 이동 버튼

## 이미지 교체
`images` 폴더의 네 파일을 네가 준비한 투명 PNG로 교체하면 됩니다.

- `player.png` : 이동하는 기본 꿈별이
- `tidy.png` : 깔끔한 룸메이트
- `quiet.png` : 조용한 룸메이트
- `active.png` : 활발한 룸메이트

파일명은 그대로 유지하세요.

## GitHub Pages
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `game.js`, `images` 폴더를 그대로 업로드합니다.
3. GitHub 저장소의 Settings → Pages에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.


## 배경
`campus-bg.png`가 게임 배경으로 사용됩니다. HUD와 캐릭터 이동 시스템은 그대로 유지됩니다.
